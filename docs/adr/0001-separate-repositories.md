# ADR-0001. Frontend и backend в отдельных репозиториях

Дата: 2026-10-16 · Статус: принято

Вместо монорепо из PRD 18.1 — два репозитория: `orbit-web` и `orbit-server`. Полный текст решения —
в `orbit-server/docs/adr/0001-separate-repositories.md`. Для клиента это значит: типы API генерируются
из опубликованной `openapi.yaml` сервера, а не из соседней папки.
